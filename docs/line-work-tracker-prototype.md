# LINE Work Tracker Prototype

ต้นแบบนี้ใช้สำหรับยืนยันรูปแบบการทำงานก่อนเชื่อม LINE Messaging API กับ Booking Delivery จริง

## พฤติกรรมที่จำลอง

- พิมพ์ทะเบียนเต็มหรือเลขท้าย 4 ตัว แล้วเลือก `ติดตามทั้งหมด`
- แสดงหัวข้องานของรถหนึ่งคันใน LINE และเว็บจาก state ชุดเดียวกัน
- ทุกหัวข้อเลือกได้เพียง `ยังไม่ทำ`, `ทำแล้ว ✅`, หรือ `ทำไม่ได้ ❌`
- เลือกวันส่งอู่ วันรถกลับ และวันส่งมอบได้
- งานที่ไม่ใช่ `ทำแล้ว` จะถูกรวมในข้อความติดตามงานค้าง
- แยก `สั่งเปลี่ยน` และ `เปลี่ยนเสร็จ` เป็นคนละงาน

## สิ่งที่ต้องต่อหลังยืนยันต้นแบบ

1. เพิ่ม work item schema ใน Booking Delivery โดยรองรับ `pending`, `done`, `blocked` และเก็บเวลา/ผู้แก้ไข
2. เพิ่มหัวข้อ `ล้างรถ`, `สั่งเปลี่ยนน้ำมันเครื่อง`, `สั่งเปลี่ยนแบต`, และ `เปลี่ยนแบต` โดยคง field เดิมของสปา น้ำมันเครื่อง ลอกลาย และประกัน
3. เพิ่ม API ค้นรายการด้วยทะเบียนเต็มหรือเลขท้าย 4 ตัว ถ้าพบหลายคันให้ผู้ใช้เลือก
4. เพิ่ม partial update API เพื่อแก้เพียง field ที่ผู้ใช้เลือก ไม่เขียนค่าที่ไม่ได้ส่งทับ
5. เพิ่ม LINE Flex Message สำหรับดูงานรายคัน พร้อม postback สำหรับ ✅/❌ และ datetime picker สำหรับวันที่
6. เพิ่มรายการเตือนงานค้างตามกำหนด แล้วส่งเข้ากลุ่ม LINE ที่อนุญาต
7. ผูก LINE user ID กับบัญชี Big Car CRM เพื่อบันทึกผู้แก้ไขและจำกัดสิทธิ์

ต้นแบบอยู่ที่ `/line-work-prototype` และใช้ข้อมูลในหน่วยความจำของหน้าเท่านั้น การรีเฟรชหน้าจะคืนค่าเริ่มต้น
